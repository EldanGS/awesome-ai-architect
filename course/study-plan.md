# 10-Week Study Plan

**8-10 hours per week** · [Back to course](README.md)

Tick each item as you finish it. Free credentials come from the [Free AI Certifications Tracker](../free-certifications/README.md).

## Week 0: Baseline

- [ ] Take the [mock exam](mock-exam.md) cold and record your score per domain.
- [ ] Fork this repository and create a `notes/` folder.
- [ ] Set up API access to at least two model providers (free tiers or credits) and a Python environment.

## Week 1: Foundations

- [ ] Study [Domain 1](01-ai-foundations.md).
- [ ] Lab: model selection experiment.
- [ ] Earn: Anthropic *AI Fluency: Framework and foundations*, Google *Introduction to Large Language Models*.

## Week 2: Discovery and value

- [ ] Study [Domain 2](02-discovery-and-value.md).
- [ ] Lab: use-case portfolio and ROI model.
- [ ] Earn: OpenAI Academy *Scope AI Solutions*, Microsoft *Create business value with AI*.

## Weeks 3-4: Reference architectures

- [ ] Study [Domain 3](03-reference-architectures.md).
- [ ] Read *Building effective agents* and the MCP specification overview.
- [ ] Lab: routing workflow, then RAG, then agent with an MCP tool.
- [ ] Earn: Anthropic *Introduction to Model Context Protocol*, Microsoft *Applied Skills: Develop an agent with integrated tools*, AWS *Agentic AI Demonstrated*.

## Week 5: Data architecture

- [ ] Study [Domain 4](04-data-architecture.md).
- [ ] Lab: retrieval bake-off with permission test.
- [ ] Earn: Google *Vector Search and Embeddings*, Microsoft *Introduction to retrieval-augmented generation concepts*.

## Week 6: Model platform and cost

- [ ] Study [Domain 5](05-model-platform-and-cost.md).
- [ ] Lab: cost and latency model with a gateway fallback test.
- [ ] Earn: Anthropic *Claude with Amazon Bedrock* or *Claude with Google Cloud's Vertex AI*.

## Week 7: Evaluation and LLMOps

- [ ] Study [Domain 6](06-evaluation-and-llmops.md).
- [ ] Lab: evaluation gate in CI and tracing.
- [ ] Earn: Google *Machine Learning Operations (MLOps) for Generative AI*, AWS *MLOps Demonstrated*.

## Week 8: Security and responsible AI

- [ ] Study [Domain 7](07-security-and-governance.md).
- [ ] Lab: threat model and red team.
- [ ] Earn: Google *Security in the World of AI*, Microsoft *Embrace responsible AI principles and practices*.

## Week 9: Cloud implementation

- [ ] Study [Domain 8](08-cloud-implementation.md) for your target cloud.
- [ ] Lab: deploy, review against well-architected pillars, write ADRs.
- [ ] Retake the mock exam. Target: 80% or higher.

## Week 10: Capstone and exam booking

- [ ] Complete the [capstone](capstone.md) and run a peer design review.
- [ ] Choose and book a vendor exam from [certifications.md](../certifications.md).
- [ ] Use the vendor's official exam guide and practice test to close remaining gaps.
- [ ] Add the completion badge and your capstone link to your profile.
